SimpleRPG2026

Ролевое приложение на C# и WPF

Аннотация

SimpleRPG2026 — учебный проект, сделанный в рамках проектной практики. Это игра, где можно управлять героем, ходить по 17 локациям, бить врагов, торговать, выполнять квесты и прокачиваться.

Написано на C# с использованием WPF в Visual Studio 2026. Реализованы: карта, боевая система, инвентарь с крафтом, квесты, торговля, уровни, смерть и возрождение.

Кратко о механиках

  • 17 локаций — перемещение по кнопкам направлений
  • 3 типа врагов — поочерёдный бой, можно лечиться
  • Инвентарь — предметы, количество, стоимость, рецепты
  • Квесты — два примера с наградами (опыт, золото, предметы)
  • Торговля — покупка и продажа у торговцев
  • Прокачка — опыт → уровень → максимум здоровья

Технологии

  • C# (.NET)
  • WPF (Windows Presentation Foundation)
  • Microsoft Visual Studio 2026
  • MVVM, привязка данных

О проекте

Цели, задачи и что сделано

Цель

Разработать простое ролевое приложение на C# с WPF, которое включает: перемещение по карте, бои, торговлю, инвентарь, квесты и развитие персонажа.

Задачи (10 пунктов)

  1. Сделать интерфейс на WPF.
  2. Карта из 17 локаций.
  3. Характеристики и прокачка персонажа.
  4. Инвентарь и крафт по рецептам.
  5. Система квестов.
  6. Боевые столкновения.
  7. Торговля с NPC.
  8. Получение опыта, золота, предметов.
  9. Смерть и возрождение.
  10. Динамическое управление (кнопки появляются/исчезают).

Реализованные системы

  • UI — разделы: персонаж, инвентарь, квесты, события, локация, управление.
  • Карта — 17 локаций с названиями, описаниями, картинками; переходы по сторонам света.
  • Персонаж — Pete, класс Fighter. Здоровье, золото, опыт, уровень. Макс. здоровье зависит от уровня.
  • Инвентарь — предметы с количеством и ценой. Можно получать, покупать, крафтить, использовать (лечение).
  • Рецепты — создание предметов из ресурсов.
  • Квесты — «Clear the herb garden» и «Clear clean path in the forest» с наградами.
  • Бой — по очереди, можно лечиться, победа даёт награды.
  • Торговля — окно с инвентарём игрока и товарами торговца.
  • Смерть — при 0 HP возврат на старт с полным здоровьем.
  • Логи — все события пишутся в центральную область.

10 марта 2026

Старт: интерфейс и карта

Сделали макет окна: разделы для характеристик, инвентаря, квестов, событий, локации и кнопок. Нарисовали карту из 17 локаций с переходами по направлениям. Кнопки перемещения появляются в зависимости от локации.
