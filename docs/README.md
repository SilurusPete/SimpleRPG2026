# Документация по учебной (проектной) практике

## 1. Введение

В рамках практики была поставлена задача разработать простенькую текстовую RPG игру «SimpleRPG2026». Целью являлось не только реализовать базовый геймплей, но и внедрить вариативные механики.

В данном отчёте описан процесс работы над проектом, распределение задач, принятые архитектурные решения, возникшие сложности и итоговые результаты.

## 2. Планирование и распределение задач

На начальном этапе мы решили разработать игру, так как мы поступаем на геймдев и выполнение подобного проекта должно дать нам базовое представление, как делаются игровые проекты. Игру которую мы решили сделать - это простенькая текстовая RPG игра.

**Основные этапы:**
1. Планировка игры.
2. Написание кода игры.
3. Написание кода UI игры.
4. Тестирование и отладка 
5. Оформление документации 

## 3. Ход выполнения работы

Написание кода, создание рисунков для локаций и монстров, тестирование и отладка, верстка сайта, документация работы.

## 5. Тестирование

Проводилось ручное функциональное тестирование по чек-листу:
 - Все базовые механики RPG работают корректно.
 - Кнопки показываются только когда нужно, что не дает пользователям сломать игру нежелательным инпутом.
 - Использование кнопок производит соответствующие им функции.
 
Критических багов не обнаружено.
